📚 授業資料RAGチャットボット

授業のPDF資料をアップロードすると、その内容をもとに質問に答えてくれる、個人用の学習支援チャットボットです。RAG（検索拡張生成）の仕組みを実際に手を動かして理解するために、AWS Certified AI Practitioner（AIF-C01）の学習と並行して開発しました。

🎯 作った理由

AIF-C01の学習でRAGやベクトル検索の概念を勉強する中で、「実際に自分の手で動かしてみないと本当の意味で理解できない」と感じ、教科書の内容をそのまま実装することにしました。授業資料を読み込ませて質問できるようにすることで、テスト勉強の効率化という実用的な目的も兼ねています。

✨ できること
PDF形式の授業資料をアップロードすると、自動でテキストを抽出・分割
質問すると、資料の中から関連する部分を検索し、その内容に基づいて回答を生成
チャット形式で会話履歴を保持しながら、複数の質問に連続して回答
すべてローカル環境で完結するため、API利用料が一切かからず、資料が外部に送信されることもない
🛠 使用技術
役割	使用技術
フロントエンド	Streamlit
PDF読み込み	pdfplumber
埋め込み（ベクトル化）	sentence-transformers（paraphrase-multilingual-MiniLM-L12-v2）
ベクトル検索	FAISS（Meta製）
回答生成（LLM）	Ollama（Llama 3、ローカル実行）
# 🔍 仕組み（RAGパイプライン)                                               
- ① PDFアップロード
- ② テキスト抽出・チャンク分割（400文字単位、50文字オーバーラップ）  
- ③ sentence-transformersで埋め込みベクトルに変換  
- ④ FAISSにベクトルを保存  
- ⑤ 質問文をベクトル化し、類似度の高い上位3チャンクを検索  
- ⑥ 検索結果と質問をOllama（Llama 3）に渡して回答を生成  
- ⑦ Streamlit上にチャット形式で表示


💡 工夫した点
コストゼロで完結する設計：クラウドAPIを使わず、埋め込み・LLMともにローカルで動かすことで、料金を気にせず何度でも試せる構成にした
プライバシー配慮：授業資料が外部サーバーに送信されないため、大学の講義資料でも安心して利用できる
チャンクのオーバーラップ設計：文の意味が分割の境目で途切れないよう、チャンク同士を意図的に重ねて分割している


🚀 セットアップ・実行方法
前提
Python 3.10以上
Ollama がインストール済みであること

# 手順

# 必要なライブラリをインストール
pip install streamlit sentence-transformers faiss-cpu pdfplumber ollama

# Llama 3モデルをダウンロード
ollama pull llama3

# アプリを起動
streamlit run app.py

ブラウザが自動的に開き、PDFをアップロードして質問できる画面が表示されます。
